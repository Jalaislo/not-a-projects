# 28. Find the Index of the First Occurrence in a String

Given two strings `needle` and `haystack`, return the index of the first occurrence of `needle` in `haystack`, or `-1` if `needle` is not part of `haystack`.

> ### Example 1:
> <p><strong>Input:</strong> haystack = "sadbutsad", needle = "sad"<br>
> <strong>Output:</strong> 0<br>
> <strong>Explanation:</strong> "sad" occurs at index 0 and 6. The first occurrence is at index 0, so we return 0.</p>

> ### Example 2:
> <p><strong>Input:</strong> haystack = "leetcode", needle = "leeto"<br>
> <strong>Output:</strong> -1<br>
> <strong>Explanation:</strong> "leeto" did not occur in "leetcode", so we return -1.</p>
